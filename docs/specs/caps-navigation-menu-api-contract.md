## Internal boundary and excluded extensions

`CapsNavigationMenuPanel` is marked @internal at caps-navigation-menu-content.ts:18 and is absent from the public barrel. Its content TemplateRef input, className, navOffset, native language transfer and panel view query (lines39–43) are adapter implementation, not additional exported consumer API. Consumers import only the secondary entrypoint and tuple above.
The existing `BrnNavigationMenuList` API is represented by Capsule's owned list anatomy; there is no new list/portal/viewport export. Existing Helm source and public Brain tokens/classes remain unchanged.
Capsule does not add route/router, item-array, trigger-policy rename, size, theme, variant, action menu, selection event, persistence or form-control properties. Shared CapsLink context is internal and does not alter its package API.
