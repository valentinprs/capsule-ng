# Capsule Message

Import `CapsMessageImports` from `@capsule-ng/caps/message`.

Properties follow [Spartan Message](https://www.spartan.ng/components/message): `CapsMessage.align: 'start' | 'end'` defaults to `start`. `CapsMessageAvatar`, `CapsMessageContent`, `CapsMessageHeader`, `CapsMessageFooter` and `CapsMessageGroup` have no inputs. None has custom outputs.

Project author, Avatar, native time, status and actions using these structural slots. Each message is an article with no imposed live region; its descendants remain neutral containers. See [conversation anatomy](../../../docs/specs/caps-messages.md).
